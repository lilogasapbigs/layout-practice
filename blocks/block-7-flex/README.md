# блок 7. flexbox база

сделал flex-меню, центрирование блока, сетку карточек, команду и панель действий.

где затупил: центрирование по двум осям сначала легко спутать. в родительском блоке поставил `align-items: center` и `justify-content: center`.

для карточек использовал `gap` и `flex-wrap`, чтобы элементы не прилипали и переносились аккуратно.
