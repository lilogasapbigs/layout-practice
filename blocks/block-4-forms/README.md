# блок 4. формы

сделал форму регистрации, фильтр каталога, обратную связь и большую анкету.

где затупил: в большой анкете полей много, поэтому сначала всё выглядело одной длинной простыней. разбил на `fieldset`, так стало понятнее.

для обязательных полей добавил `required`, а типы input подбирал по смыслу: email, tel, date, file, range и другие.
